ROAST — Complete Weekly Operating System v8
Thursday gathers. Sunday assesses, then produces what's earned.
v8 is angle-first and judgment-led. The old "17 outputs, produce in order" list is now a FORMAT LIBRARY the weekly editorial assessment selects from — nothing gets made just because it has a slot. Every Sunday runs in two stages: the Editorial Assessment (find the week's strongest story, rank by argument, decide what deserves production) → an approval gate → production of the approved slate only. The Brand Bible governs alexa.realtor. One rule still governs all of it: a topic lives in exactly one home, and everything else links to it — never re-reports it.
⚖ The v8 Core — Two Stages, Every Sunday
The system no longer produces a batch and decides later. It assesses first, produces second, and Alexa approves in between.
Stage 1
Editorial Assessment
Read all research → find the week's single strongest story → rank opportunities by ARGUMENT (not topic) → produce / optional / monitor / skip-with-reason → recommend format (never default to video). No content written.
Gate
Alexa Approves
Review the slate. Approve, cut, or edit. Name exactly what gets made — "do it all" is the old slot-filling trap.
Stage 2
Production
Produce ONLY the approved slate from the format library. Ledger first. Every piece checked against AEO, no-duplication, voice, verification, gating. Packet last.
Stage 1 stops and waits. Never produce before approval.
Why: this retires the v7 default where every research item became a post. Fewer weak outputs, stronger arguments, clearer priorities — content that is unmistakably Alexa.
